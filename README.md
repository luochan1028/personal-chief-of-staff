# 个人 AI 参谋 · 原型骨架使用说明

## 一句话

输入一句话（“帮我准备明天”），智能体自主规划并调用工具完成多步骤任务，全程留执行轨迹，结尾输出量化指标。

## 运行（无需 API Key）

```bash
cd ~/workspace/dubai-hackathon/prototype
python3 demo.py
```

演示模式用内置规则规划，不冒充大模型。输出包括：每步工具调用结果、人工干预次数（0）、任务完成率、耗时，以及 data/ 下生成的三件产物（明日计划备忘、课前小测草稿、提醒）。

## 接真实大模型（可选）

```bash
export LLM_API_KEY='[待填]'
export LLM_BASE_URL='[待填 OpenAI 兼容接口地址]'
export LLM_MODEL='[待填]'
python3 demo.py
```

调用失败自动回落规则规划，不中断演示。

## 文件说明

- `agent.py`：规划＋执行主循环（规则规划／大模型规划两档）。
- `tools.py`：工具箱（课表、待办、小测草稿、备忘、提醒），读写本地 JSON。
- `demo.py`：演示脚本，输出顺序即演示视频拍摄顺序。
- `data/`：演示用虚构数据，不含任何真实个人信息。

## 演示视频分镜（60～90 秒）

1. 输入一句话指令（特写）。
2. 规划步骤逐条出现。
3. 工具执行过程快剪（课表、待办、小测、备忘、提醒）。
4. 结尾字幕：人工干预 0 次、5／5 步完成、耗时数秒（人工约 40 分钟）。
